# Отчёт о багах

## Баг 1: ложное срабатывание проверки дубликатов
- **Шаги воспроизведения:** добавить "Капитанская дочка" (Пушкин)
- **Ожидаемое поведение:** книга добавляется
- **Фактическое поведение:** сообщение "Книга уже есть"
- **Причина:** сравнение только по автору (`book["author"] == "Пушкин"`)
- **Исправление:** сравнение по названию и автору (`book["title"] == title and book["author"] == author`)

## Баг 2: удаление не сохраняется
- **Шаги воспроизведения:** удалить книгу, перезапустить программу
- **Ожидаемое поведение:** книга остаётся удалённой
- **Фактическое поведение:** книга появляется снова
- **Причина:** функция `save_books` не вызывалась внутри `remove_book`
- **Исправление:** вызов `save_books(books)` добавлен непосредственно внутрь функции
