# Library — Учёт книг

## Что делает программа
Программа для учёта книг в библиотеке: добавление, удаление, сохранение данных в формате JSON и ведение логов операций.

## Исправленные баги
1. **Баг 1 (ложные дубликаты):** Проверка сравнивала только автора. Исправлено на сравнение по названию и по автору одновременно.
2. **Баг 2 (удаление не сохранялось):** Удаление происходило только в памяти. Вызовы сохранения вынесены внутрь функций `add_book` и `remove_book`.

## Как запустить
bash

python main.py
## Где лежат данные и логи
- `data/books.json` — база данных книг
- `logs/operations.log` — журнал операций
- `docs/bug-report.md` — подробный отчет об исправленных багах
